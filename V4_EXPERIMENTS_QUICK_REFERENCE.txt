🎯 实验分组概览
================================================================================

Group 1: Core Baselines (4个实验)
  - baseline_v4:           纯UNet，不含PVT
  - pvt_frozen_v4:         PVT冻结，无Adapter
  - adapter_frozen_v4:     PVT冻结，启用Adapter

  - loss_weighted_v4:      调整loss权重

Group 3: Fusion Strategies (3个实验)
  - fusion_v1_adaptive_v4: Adaptive weights融合
  - fusion_v2_attention_v4: Cross-attention融合
  - fusion_combined_v4:    融合 + 边缘监督

Group 4: Learning Rate Tuning (2个实验)
  - adapter_lr_tuned_v4:   adapter_lr=5e-5
  - adapter_lr_high_v4:    adapter_lr=5e-4

Group 5: Complete Configurations (3个实验)
  - complete_balanced_v4:  平衡配置
  - complete_aggressive_v4: 激进配置（PVT可训练）
  - complete_lite_v4:      轻量配置

🔑 关键参数说明
================================================================================

学习率 (lr):
  5e-5   - 标准学习率（用于frozen配置）
  2e-5   - 降低学习率（用于PVT微调，防止catastrophic forgetting）

Adapter学习率 (adapter_lr):
  1e-4   - 标准值
  5e-5   - 降低值（更温和的参数更新）
  5e-4   - 提高值（更激进的参数更新，可能过度）

batch_size:
  固定为8（所有实验）

num_channels:
  128 - 所有实验（标准通道数）

image_size:
  256 - 标准尺寸（v4数据预处理）

PVT融合 (use_pvt_fusion):
  False - 不使用PVT特征
  True  - 使用Pyramid Vision Transformer特征

PVT冻结 (freeze_pvt):
  True  - PVT参数完全冻结（仅使用预训练特征）
  False - PVT参数完全可训练（需要降低学习率）

Adapter (use_adapter):
  False - 不使用参数高效微调
  True  - 启用PVT Adapter（参数量减少，学习率独立控制）

Edge分支 (use_edge_branch):
  False - 不使用边缘分支（3通道输出）
  True  - 启用边缘分支（4通道输出：3分割+1边缘）

FEB (use_feb):
  False - 不使用特征增强模块
  True  - 启用Feature Enhancement Branch

CrossAttn (use_cross_attn):
  False - 不使用交叉注意力
  True  - 启用UNet与PVT之间的交叉注意力

Fusion版本 (fusion_version):
  None  - 使用标准的门控融合（如果use_pvt_fusion=True）
  'v1'  - 自适应权重融合（per-scale adaptive weights）
  'v2'  - 交叉分支注意力融合（multi-head attention）

Loss函数：
  use_edge_loss:  边缘监督loss，权重0.2-0.3
  use_sdf_loss:   距离场loss，权重0.2-0.3
  use_hd_loss:    Hausdorff距离loss，权重0.1-0.15

🚀 快速命令参考
================================================================================

1. Baseline (最简单):
   python scripts_new/segmentation_train_gate_v4.py \
       --data_dir ./data/mydata \
       --out_dir ./results/train/v4_baseline \
       --batch_size 8 --lr 5e-5

2. PVT Frozen (标准推荐):
   python scripts_new/segmentation_train_gate_v4.py \
       --data_dir ./data/mydata \
       --out_dir ./results/train/v4_pvt_frozen \
       --batch_size 8 --lr 5e-5 \
       --use_pvt_fusion True --freeze_pvt True --use_feb True

3. Adapter (参数高效):
   python scripts_new/segmentation_train_gate_v4.py \
       --data_dir ./data/mydata \
       --out_dir ./results/train/v4_adapter \
       --batch_size 8 --lr 5e-5 --adapter_lr 1e-4 \
       --use_pvt_fusion True --use_adapter True

4. 多Loss (全功能):
   python scripts_new/segmentation_train_gate_v4.py \
       --data_dir ./data/mydata \
       --out_dir ./results/train/v4_multi_loss \
       --batch_size 8 --lr 5e-5 \
       --use_edge_branch True \
       --use_edge_loss True --edge_loss_weight 0.2 \
       --use_sdf_loss True --sdf_loss_weight 0.2 \
       --use_hd_loss True --hd_loss_weight 0.1

5. 完整配置 (平衡):
   python scripts_new/segmentation_train_gate_v4.py \
       --data_dir ./data/mydata \
       --out_dir ./results/train/v4_complete_balanced \
       --batch_size 8 --lr 5e-5 --adapter_lr 1e-4 \
       --use_pvt_fusion True --freeze_pvt True --use_feb True \
       --use_cross_attn True \
       --use_adapter True --adapter_reduction 16 \
       --use_edge_branch True --fusion_version v2 \
       --use_edge_loss True --edge_loss_weight 0.2 \
       --use_sdf_loss True --sdf_loss_weight 0.2 \
       --use_hd_loss True --hd_loss_weight 0.1

6. 采样和评估:
   python scripts_new/segmentation_sample_gate_v4.py \
       --model_path ./results/train/{exp_name}/model_best.pt \
       --data_dir ./data/mydata \
       --out_dir ./results/sample/{exp_name} \
       --num_ensemble 5 --save_vis
