🔑 关键参数解释
================================================================================

学习率 (lr):
  5e-5   - 标准学习率（用于frozen和初始阶段）
  2e-5   - 降低学习率（用于PVT微调时）

batch_size:
  固定为8（所有实验）

num_channels:
  128    - train_no (全尺寸模型)
  32     - 其他所有（轻量级，用于PVT融合）

PVT融合 (use_pvt_fusion):
  False  - 不使用PVT特征
  True   - 使用Pyramid Vision Transformer特征

FEB (use_feb):
  False  - 不使用Feature Enhancement Branch
  True   - 启用特征增强分支

CrossAttn (use_cross_attn):
  False  - 不使用交叉注意力
  True   - 启用UNet与PVT之间的交叉注意力机制

PVT训练模式 (pvt_train_mode):
  frozen          - PVT参数完全冻结
  last_stage      - 仅训练PVT最后一个阶段
  last_two_stages - 训练PVT最后两个阶段

Patch-Mix参数:
  train_long_side    = 640    - 原始数据长边缩放到640
  patches_per_image  = 6      - 每张原始图切成6个patch
  fg_sample_ratio    = 0.6    - 60%的patch包含前景
  min_fg_pixels      = 32     - 前景最少32像素
  full_image_ratio   = 0.6    - 60%概率保留完整图像
  intensity_aug_p    = 0.4    - 40%概率进行强度增强

采样方法:
  Global Only       - 整张图采样（E2, E2.5）
  Local Window      - 640x640的滑窗采样（E3）
  Global+Local      - 全局和局部融合（E4, fusion_alpha=0.4）

💡 推荐实验设计流程
================================================================================

Step 1: Baseline (推荐使用train_pvt或E1配置)
  python scripts_new/segmentation_train_gate_v4.py \
      --lr 5e-5 --batch_size 8 --use_adapter --use_edge_branch

Step 2: 尝试高级损失函数
  添加: --use_edge_loss --use_sdf_loss --use_hd_loss

Step 3: 尝试融合策略
  修改: --fusion_version v1/v2

Step 4: 尝试PVT微调 (基于E5/E6)
  修改: --freeze_pvt False (需要降低学习率到2e-5)

Step 5: 复杂采样
  python scripts_new/segmentation_sample_gate_v4.py \
      --num_ensemble 5 --save_vis

🎯 快速命令参考
================================================================================

对标E1的v4训练:
  python scripts_new/segmentation_train_gate_v4.py \
      --data_dir ./data/mydata \
      --out_dir ./results/train/e1_v4 \
      --lr 5e-5 \
      --batch_size 8 \
      --use_adapter \
      --use_edge_branch \
      --use_edge_loss

对标E5的v4训练 (PVT微调):
  python scripts_new/segmentation_train_gate_v4.py \
      --data_dir ./data/mydata \
      --out_dir ./results/train/e5_v4 \
      --lr 2e-5 \
      --batch_size 8 \
      --use_adapter \
      --use_edge_branch \
      --use_edge_loss \
      --use_sdf_loss \
      --use_hd_loss \
      --freeze_pvt False

v4采样（对标E2-E4）:
  python scripts_new/segmentation_sample_gate_v4.py \
      --model_path ./results/train/e1_v4/model_best.pt \
      --data_dir ./data/mydata \
      --out_dir ./results/sample/e1_v4 \
      --num_ensemble 4 \
      --save_vis
